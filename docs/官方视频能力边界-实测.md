# 官方「视频能力」真实边界（实测取证，2026-10）

> 这份文档推翻本仓库早期文档里的两个错误结论：
> 1. 「视频编辑工程（openchatcut）是换服务商后的结构性缺口」→ **错**。编辑层是纯本地开源应用，与服务商无关。
> 2. 「Hub agent 是 `minimax-video` 插件的硬阻断」→ **错**。`hub_*` 属于另一个插件 `minimax-h3-skills`。
>
> 所有结论均来自本机只读取证，下面逐条给路径、行号和原文。

---

## 0. 一句话结论

**「视频编辑」整块能力本来就与服务商无关**（官方插件自带的 OpenChatCut 改造版，AGPL-3.0-or-later，本机跑）；
**真正被官方锁死在云端的只有「生成」这一个动作的落地位置**（宿主 Agent 调 `connector__matrix__submit_video_generation`，
执行体在 `agent.minimax.cn`，走你的 MiniMax 账号额度）。

换服务商 = 替换这一个动作的落地位置；其余部分原样保留。

## 6. 但有一个真实的协议落差：上游走 V1，中转站只认 V2

中转站免鉴权探测（预期 401/404，不产生计费）：

```
GET https://api.lk888.ai/v2/video_generation
→ 404 {"error":{"message":"Invalid URL (GET /v2/video_generation). 本平台 /v2/* 仅提供 MiniMax 官方视频格式：
   POST /v2/video_generation、POST /v2/video_regeneration、GET /v2/query/video_generation、
   GET /v2/query/video_generation/{task_id}、DELETE /v2/video_generation/{task_id}。
   H3-Context-IR 未开放：POST /v2/h3_context_ir 会返回 400。"}}

GET https://api.lk888.ai/v1/video_generation?task_id=1
→ 404 "本平台不提供 OpenAI 视频格式端点（POST /v1/videos、GET /v1/videos、/v1/videos/{id}/content 等）。"

GET https://api.lk888.ai/v1/query/video_generation?task_id=1
→ 404 "调用路径需以 /v1/ 开头(例如 /v1/chat/completions、/v1/messages、/v1/skills/models)。"

GET https://api.lk888.ai/v1/files/retrieve?file_id=1
→ 404（同上）

GET https://api.lk888.ai/v1/skills
→ 401 missing_api_key   ← 平台完整接口清单需真实 key 才能读
```

**结论**：

* 中转站 `/v2/*` = MiniMax 官方 **V2** 格式（`content[]` 数组，支持 `text` / `image_url` / `video_url` / `audio_url`，多镜头、`callback_url`、`extra.prompt_expansion_mode`）；
* 中转站 `/v1/*` = OpenAI 兼容的 chat / messages / skills，**不提供** MiniMax V1 视频路径，也不提供 OpenAI `/v1/videos`；
* 所以「把 `MINIMAX_BASE_URL` 指到中转站」会 **404**，必须做 **V1 → V2 的请求改写**（body 形状、query 路径、`files/retrieve` 替代）；
* **这正是本仓库 `server.py` 已经在做的事**。

## 7. 修订后的能力矩阵

| 能力 | 官方由谁提供 | 换服务商后 |
| --- | --- | --- |
| 多轨剪辑 / 字幕 / 特效 / 模板 / 剪映草稿导出 | `minimax-video` 插件内置 OpenChatCut，**本机** | ✅ 原样保留（保留官方插件即可） |
| Agent 剪辑（草稿 → 预览 → 应用） | 本机 MCP + 宿主 Agent | ✅ 原样保留 |
| 视频生成（提交/轮询/成片） | 宿主 `connector__matrix__submit_video_generation` → **云端** | ⚠️ 必须换落地位置 ← **本仓库干的就是这个** |
| 视频修改 / 升 2K | 同上 + `regenerate` 路由 | ⚠️ 同上 |
| 配音 / 音乐 / 生图 | 宿主 connector 工具 → 云端 | ⚠️ 中转站是否覆盖未验证 |
| Lucid 配音（`voice.provider=mcode`） | skill 直接 shell 调 `mcode-tools connector tool connector__matrix__synthesize_speech` | ❌ CLI 路径只到云端，本地换不掉 |
| 代码动画（code-video / lucid 渲染） | 本地 Python + Remotion | ✅ 原样保留 |
| Hub 编排（`hub_*`） | `minimax-h3-skills` 插件 → 需 Hub 服务端 | ❌ 需另一个插件 + 服务端 |
| Drive 资产（`node_id` / `get_asset_url`） | MiniMax 云 | ❌ 云端专属 |
